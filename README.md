\# RetailCommerce



\## About

RetailCommerce is an Android e-commerce application developed as part of my mobile application development work. The project focuses on providing a mobile platform for online retail activities.



\## Project Overview

The application is developed for Android using Android Studio and Gradle. The project source code is organized into an Android application module and supporting project configuration files.

\- Android SDK

\- Android Studio

\- Gradle

\- Git and GitHub
